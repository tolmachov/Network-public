# IP-подсети российских сервисов

Список IP-подсетей российских сервисов, банков, операторов связи и другой инфраструктуры. Подсети собраны по ASN — номерам автономных систем — из публичных данных [RIPE Stat](https://stat.ripe.net/).

В файле **[update-lists.rsc](update-lists.rsc)** опубликованы два списка в формате address-list для MikroTik RouterOS:

- `ru-services` — IP-подсети российских сервисов и инфраструктуры.
- `rkn` — IP-подсети некоторых сервисов, блокируемых Роскомнадзором.

Способ использования списков остаётся на усмотрение пользователя.

Это не список всех российских IP-адресов и не полный перечень адресов каждого сервиса. В него входят сети операторов и хостеров, которые могут обслуживать множество сторонних сайтов, а также зарубежная инфраструктура, например AliExpress / Alibaba.
